About QuickNotes

QuickNotes is a simple note-taking app designed to help you capture ideas quickly and easily.

How to use QuickNotes

  1. Type your note in the input field.
  2. Click "Add Note" to save it.
  3. Your notes will be displayed below.

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the selected note
